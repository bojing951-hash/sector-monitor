## 🔧 技术架构

### 数据获取
- **美股**: yfinance (Yahoo Finance API)
- **A股**: akshare (东方财富数据源)

### 数据处理
- **收益率计算**: 20日、60日
- **相对强度**: 相对基准指数的差值
- **综合得分**: 多时间周期平均

### 可视化
- **库**: matplotlib (中文支持)
- **格式**: PNG (300 DPI)
- **字体**: Arial Unicode MS, SimHei

### 历史存储
- **格式**: CSV
- **内容**: 日期、代码、名称、排名、得分
- **用途**: 周度对比、趋势追踪
