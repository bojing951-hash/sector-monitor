## 📖 如何解读报告

### 1. 查看Top 5

**美股Top 5** → 关注强势板块和主题
```
🔥 1. 白银 - 综合得分 +21.68

   - 20日涨幅 -17.53% → 近期回调
```

**A股Top 5** → 寻找投资机会
```
📈 1. 有色金属 (512400)
   - 综合得分 +12.72
   - 60日涨幅 +25.89% → 中期趋势向上
   - 20日涨幅 +0.73% → 短期震荡
```

### 2. 趋势标识

| 趋势 | 含义 | 策略 |
|------|------|------|
| 🔥 strong_up | 强势上涨 | 积极关注 |
| 📈 upgrading | 正在升级 | 逢低布局 |
| ➡️ neutral | 中性震荡 | 观望等待 |
| 📉 downgrading | 正在降级 | 谨慎持有 |
| 💔 weak_down | 弱势下跌 | 规避风险 |

### 3. 综合得分

**正值**: 强于基准指数
- 得分 > +10: 明显强势
- 得分 +5 ~ +10: 相对强势
- 得分 0 ~ +5: 略强于基准

**负值**: 弱于基准指数
- 得分 < -10: 明显弱势
- 得分 -10 ~ -5: 相对弱势
- 得分 -5 ~ 0: 略弱于基准

## ⚠️ 常见问题

### Q1: 运行时出现SSL错误
**A**: 这是网络问题，系统会自动跳过失败的ETF，不影响其他数据获取。

### Q2: 某些ETF显示"N/A"
**A**: 该ETF数据不足20或60个交易日，等待数据累积即可。

### Q3: 历史对比没有显示
**A**: 第一次运行时没有历史数据，第二次运行才会显示对比。

### Q4: 图表中文显示为方框
**A**: 系统已配置中文字体，如仍有问题请安装中文字体。

### Q5: 如何自定义时间周期
**A**: 修改代码中的 `days=[20, 60]` 为你需要的周期。
