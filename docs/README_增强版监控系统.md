## 趋势识别系统

### 趋势类型

**🔥 强势上涨 (Strong Up)**
- 条件：得分>5 且 4周涨幅>0
- 策略：重仓参与，持有龙头
- 示例：半导体板块在AI爆发期

**📈 正在升级 (Upgrading)**
- 条件：4周和12周涨幅都>0
- 策略：开始关注，小仓位试探
- 示例：主题刚刚获得市场认可

**➡️ 中性 (Neutral)**
- 条件：涨跌混合，无明确趋势
- 策略：观望，等待信号

**📉 正在降级 (Downgrading)**
- 条件：4周和12周涨幅都<0
- 策略：减仓，锁定利润
- 示例：主题资金开始流出

**💔 弱势下跌 (Weak Down)**
- 条件：得分<-5 且 4周涨幅<0
- 策略：离场，避免参与
- 示例：主题失去动能

### 如何使用趋势信息

**每日流程：**
1. 查看报告，识别🔥强势主题
2. 在强势主题中选择龙头股
3. 等待技术面确认（日线收紧）
4. 设置止损和止盈

**每周流程：**
1. 回顾主题清单
2. 添加新的📈升级主题
3. 移除💔弱势下跌主题
4. 更新观察名单

## 主题维护指南

### 添加主题的标准

**1. 技术面验证:**
- 主题ETF保持结构
- 出现更高的低点
- 成交量放大

**2. 个股验证:**
- 龙头个股放量突破
- 多只个股同步走强

**3. 基本面驱动:**
- 政策支持（国家战略、部委文件）
- 产业催化剂（技术突破、订单落地）
- 叙事清晰（故事性强，易于传播）

### 移除主题的信号

- ❌ 主题ETF跌破关键支撑
- ❌ 龙头股开始走弱
- ❌ 失去相对强度（跑输大盘）
- ❌ 政策面转冷或证伪
- ❌ 市场关注度下降

### 维护频率

**每日:**
- 浏览主题监控列表
- 观察趋势变化
- 记录异常波动

**每周:**
- 回顾主题表现
- 添加新兴主题
- 移除弱势主题
- 更新优先级

**每月:**
- 深度回顾主题清单
- 清理长期无效主题
- 评估主题分类
- 优化监控系统

### 调整排名周期

默认使用4周和12周，可以修改：

```python
# 在calculate_returns方法中修改
weeks = [2, 4, 8, 12]  # 添加2周和8周
```

### 调整趋势阈值

在 `identify_trends` 方法中修改：

```python
# 修改强势上涨的阈值
strong_mask = (rankings['score'] > 8) & (rankings['4w_return'] > 0)  # 从5改为8

# 修改弱势下跌的阈值
weak_mask = (rankings['score'] < -8) & (rankings['4w_return'] < 0)  # 从-5改为-8
```

## 常见问题

**Q1: 主题监控和板块轮动有什么区别？**

A1:
- **板块轮动**: 关注11个主要板块，每周回顾，适合确定大方向
- **主题监控**: 覆盖30+细分主题，每日浏览，适合捕捉细分机会
- **组合使用**: 板块定方向，主题找机会

**Q2: 如何解读趋势标记？**

A2:
- 🔥 强势上涨：重仓参与
- 📈 正在升级：开始关注
- ➡️ 中性：观望等待
- 📉 正在降级：减仓离场
- 💔 弱势下跌：避免参与

**Q3: 需要监控所有主题吗？**

A3:
- 不需要。建议关注：
  1. 强势板块内的主题
  2. 正在升级的主题
  3. 你熟悉的行业主题
- 避免同时追踪过多细分领域

**Q4: 主题清单多久更新一次？**

A4:
- **每日**: 浏览，观察变化
- **每周**: 添加/移除主题
- **每月**: 深度回顾和优化

**Q5: A股和美股哪个更重要？**

A5:
- 取决于你的投资方向
- 如果只投资A股，重点关注A股部分
- 如果投资美股，重点关注美股部分
- 如果两者都投，两者都重要
