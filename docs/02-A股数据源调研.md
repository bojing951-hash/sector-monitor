## 🔍 数据源评估

### 1. AKShare ⭐⭐⭐⭐⭐（推荐）

**基本信息**：
- 开源项目 | GitHub: https://github.com/akfamily/akshare
- 数据类型: 行情数据、财务数据、宏观数据
- 实时性: 实时/延迟15分钟
- 成本: 完全免费

**优势**:
- ✅ 开源免费，无需注册
- ✅ 数据全面（6000+只股票）
- ✅ 更新活跃，社区支持好
- ✅ 简单易用，pandas友好
- ✅ 支持复权处理
- ✅ 文档详细

**劣势**:
- ⚠️ 数据来自东方财富等第三方
- ⚠️ 实时数据可能有延迟

**适用性**: ⭐⭐⭐⭐⭐
- 非常适合个人投资者
- 适合量化研究
- 适合历史回测

**安装**:
```bash
pip install akshare
```

**使用示例**:
```python
import akshare as ak

# 获取股票行情
df = ak.stock_zh_a_hist(symbol="000001", period="daily", start_date="20230101", adjust="")

# 获取ETF行情
```

### 2. Tushare ⭐⭐⭐⭐

**基本信息**:
- 官网: https://tushare.pro
- 数据类型: 行情、财务、宏观经济、行业数据
- 实时性: 实时
- 成本: 免费账户有积分限制（积分制）

**优势**:
- ✅ 数据专业可靠
- ✅ API稳定
- ✅ 文档完善
- ✅ 社区活跃

**劣势**:
- ⚠️ 需要注册账号
- ⚠️ 积分制（免费用户有调用限制）
- ⚠️ 高频数据需要积分

**适用性**: ⭐⭐⭐⭐
- 适合专业投资者
- 适合量化团队
- 不适合高频调用

**使用示例**:
```python
import tushare as ts

# 设置token
ts.set_token('your_token_here')

# 初始化pro API
pro = ts.pro_api()

# 获取日线行情
df = pro.daily(ts_code='000001.SZ', start_date='20230101', end_date='20230221')

# 获取ETF信息
df = pro.fund_basic(ts_code='510300.SS')
```

## 🛠️ 技术实现

### AKShare集成示例

```python
import akshare as ak
import pandas as pd
from datetime import datetime, timedelta

class AStockDataFetcher:
    """A股数据获取器"""

    def __init__(self):
        self.source = "AKShare"

    def get_etf_list(self):
        """获取所有ETF列表"""
        try:
            # 获取ETF列表
            fund_list = ak.fund_etf_category_sina(symbol="行业ETF")
            print(f"✓ 获取到 {len(fund_list)} 个行业ETF")
            return fund_list
        except Exception as e:
            print(f"✗ 获取ETF列表失败: {str(e)}")
            return None

    def get_etf_hist(self, symbol, period="3mo"):
        """获取ETF历史数据"""
        try:
            # 计算日期范围
            end_date = datetime.now().strftime("%Y%m%d")
            start_date = (datetime.now() - timedelta(days=90)).strftime("%Y%m%d")

            # 获取数据
            df = ak.fund_etf_hist_em(
                symbol=symbol,
                period="daily",
                start_date=start_date,
                end_date=end_date,
                adjust="qfq"  # 前复权
            )

            if not df.empty:
                # 重命名列
                df.columns = ['open', 'close', 'high', 'low', 'volume', 'outstanding_share']
                df.index = pd.to_datetime(df.index)

                print(f"✓ {symbol}: 获取到 {len(df)} 条数据")
                return df
            else:
                print(f"✗ {symbol}: 无数据")
                return None

        except Exception as e:
            print(f"✗ {symbol}: 错误 - {str(e)}")
            return None

    def get_spot_data(self):
        """获取实时行情"""
        try:
            spot = ak.stock_zh_a_spot_em()
            print(f"✓ 获取到 {len(spot)} 只股票的实时行情")
            return spot
        except Exception as e:
            print(f"✗ 获取实时行情失败: {str(e)}")
            return None

# 测试代码
if __name__ == "__main__":
    fetcher = AStockDataFetcher()

    # 测试获取ETF列表
    print("测试获取ETF列表...")
    etf_list = fetcher.get_etf_list()

    # 测试获取历史数据
    print("\n测试获取历史数据...")
    df = fetcher.get_etf_hist("510300.SS")

    if df is not None:
        print(f"\n最新数据:\n{df.tail(3)}")
```
